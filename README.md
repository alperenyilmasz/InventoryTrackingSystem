# Inventory Tracking & Management System

A web-based inventory and warehouse management system developed using **PHP** and **MySQL**. It is designed to track stock movements, organize categories, manage product listings, and control user access through an administrative dashboard.

---

## 🌟 Features

* **Real-Time Stock Tracking:** Manage and record stock entries (`stock_in.php`) and dispatches (`stock_out.php`).
* **Movement History & Audit:** Track all product ins and outs chronologically with detailed logs (`movements.php`).
* **Product & Category Control:** Full CRUD support for products and structured categories (`products.php`, `categories.php`).
* **Role-Based User Management:** Authentication system with user registration, login/logout, and role management (`users.php`, `register.php`, `login.php`).
* **Dashboard & Metrics:** Overview of total products, active stock alerts, and recent activities (`dashboard.php`).
* **Database Migration & Tools:** Built-in schema setup and migration scripts (`sql/`, `tools/`).

---

## 🛠️ Tech Stack

* **Backend:** PHP
* **Database:** MySQL
* **Frontend:** HTML5, CSS3, JavaScript
* **Server Environment:** Apache (XAMPP / WAMP / LAMP)
